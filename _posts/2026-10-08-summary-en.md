**「Background」** Margaret Hamilton directed the Software Engineering Division at MIT&\#x27;s Instrumentation Laboratory, where she led development of the on-board flight software for NASA&\#x27;s Apollo Guidance Computer during the Apollo program. **「Impact」** Hamilton&\#x27;s death removes a foundational figure whose Apollo work established software engineering as a discipline and whose error-handling design helped save the Apollo 11 lunar landing. ### [Chrome to Ship JPEG XL Support](https://developer.chrome.com/blog/jpeg-xl-in-chrome) ⭐️ 8.0/10

Chrome is shipping JPEG XL support, according to a first-party Chrome developer blog post. The move reverses a prior removal of the format from Chromium and could broaden web adoption of JPEG XL. Community discussion notes that Firefox is expected to include it in Stable, and that during October browser coverage will shift from Safari-only to majority coverage. Commenters describe JPEG XL as highly versatile, with AVIF retaining a slight edge in some cases such as fairly lossy compression, while cautioning that JPEG XL may be less suitable under strong CPU constraints.

hackernews · Lobsters · Oct 7, 11:25 · [Discussion](https://news.ycombinator.com/item?id=49991227)

**「Background」** JPEG XL is an image format designed to serve as a versatile replacement for older formats such as JPEG, PNG, and WebP, offering both lossless and lossy compression. Chrome previously removed JPEG XL support from Chromium after deprecating it in Chrome 110, which limited the format&\#x27;s adoption on the web because the most popular browser did not support it. The format has since seen gradual ecosystem support, including in image compression tools that list JPEG XL alongside AVIF, WebP, JPG, PNG, and APNG.

**「Impact」** Chrome&\#x27;s reversal removes the main browser barrier to JPEG XL adoption, potentially making it viable for web image delivery alongside AVIF. Broader ecosystem support remains uneven, with Firefox offering only experimental support and Safari already shipping it.

**「Community Discussion」** Commenters welcomed the reversal after Chrome previously removed JPEG XL, citing the format&\#x27;s versatility and the prior lack of support in the most popular browser as a major adoption barrier. Some preferred a single format over both JPEG XL and AVIF, and viewed the change as further marginalizing WebP, while noting ecosystem support remains uneven, with examples such as iOS 18 not working with .jxl in Photos but iOS 27 doing so.

### [Intel Driver Bug Breaks IPv6, Microsoft Cloud Services](https://www.ithome.com/1/010/369.htm) ⭐️ 8.0/10

A bug in Intel&\#x27;s Connectivity Performance Suite \(ICPS\) network driver silently resets the IPv6 Flow Label to 0 on every TCP packet after the handshake, breaking IPv6 connectivity and causing Microsoft OneNote, Microsoft 365, OneDrive, Teams, and the Azure portal to fail. The defect was traced to IntcCo11X64.sys version 11.5.11.19, part of Rivet Networks&\#x27; traffic control engine \(ICPS build 40.25.926.173\), which violates RFC 6437&\#x27;s requirement that the Flow Label remain consistent for the life of a connection; Microsoft&\#x27;s cloud edge load balancers use the label to route packets to the correct backend server, so zeroed labels send packets to servers that never joined the connection, which then return resets. A user on a Samsung Galaxy Book spent weeks on the issue, escalated to Microsoft support without resolution, and ultimately used Claude for an overnight packet-level forensic analysis that isolated ICPS. Testing showed that with ICPS active, 0 of 42 outbound packets retained the Flow Label and only 4 of 10 IPv6 connections succeeded, while disabling the INTCCoSvc driver restored all 65 packets and all 10 connections; IPv4 is unaffected because it has no Flow Label field. The user found 1,086 ICPS entries from 19 companies in the Microsoft Update Catalog with only one verified fixed version, and potential affected packages span Samsung, Lenovo, VAIO, Asus, HP, Dynabook, and Huaqin. Testing Intel&\#x27;s generic ICPS 50.26.623.243 on October 7 showed all 169 IPv6 connections succeeding versus 138 of 170 for the Windows Update OEM version, though Intel&\#x27;s release notes do not mention an IPv6 fix.

rss · IT HOME · Oct 8, 00:24

**「Background」** The IPv6 Flow Label is a 20-bit field defined in RFC 6437 that is meant to stay constant for the lifetime of a connection so network devices can consistently identify and route a flow. Microsoft&\#x27;s cloud edge load balancing relies on this field to direct packets to the backend server handling a given connection. Intel acquired Rivet Networks, whose traffic control engine is now part of Intel Connectivity Performance Suite \(ICPS\), a driver package distributed through Windows Update and OEM channels.

**「Impact」** Users of affected OEM devices from Samsung, Lenovo, VAIO, Asus, HP, Dynabook, and Huaqin that received the flawed ICPS driver via Windows Update may experience broken IPv6 connectivity and failures in Microsoft 365, OneNote, OneDrive, Teams, and Azure portal access until the driver is updated or disabled.

### [中国团队研制出钍-229核光钟](https://www.ithome.com/1/010/337.htm) ⭐️ 8.0/10

据央视新闻10月8日报道，清华大学团队联合国内多个研究团队在国际上率先研制出“核光钟”，将量子精密测量的计时基准从电子跃迁推进到钍-229原子核跃迁。团队历时近5年研发出148纳米连续波真空紫外激光技术，用该光源精确驱动放射性同位素钍-229的核跃迁，并将激光频率稳定在这一跃迁上。该“核光钟”每秒约可计数2000万亿次，被视为继原子微波钟、原子光钟之后的新一代时间频率标准。研究团队称，原子核尺寸约为核外电子云的几万分之一，核跃迁受外界扰动影响较小，可提供更稳定的计时节拍，并具备进一步小型化的潜力。团队表示其未来有望应用于导航和深空探测，为卫星、航天器提供更精准的定位和距离测量。

rss · IT HOME · Oct 7, 22:38

**「Background」** Atomic clocks have long used electron transitions in atoms as their timekeeping reference, progressing from microwave atomic clocks to optical atomic clocks. Thorium-229 is uniquely suited to a nuclear clock because its first excited nuclear state lies only about 8.4 electron volts above the ground state, corresponding to vacuum-ultraviolet light near 148 nm, a wavelength reachable by purpose-built lasers. A nuclear clock measures time by driving this thorium-229 nuclear transition with a vacuum-ultraviolet laser and counting the laser&\#x27;s oscillation cycles with frequency-comb technology.

**「Impact」** If the reported thorium-229 nuclear clock can be engineered into solid-state devices, it could bring optical-clock performance to applications currently limited by bulky atomic trapping systems, such as satellite-based navigation and synchronized digital data traffic. The source&\#x27;s claims about miniaturization and navigation/deep-space use remain forward-looking rather than demonstrated.
